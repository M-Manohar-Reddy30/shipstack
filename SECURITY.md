# Security Policy

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Report security issues privately through GitHub's security reporting
mechanisms.

When reporting a vulnerability, please include:

- A clear description of the issue
- Steps to reproduce the issue
- Potential impact
- Relevant logs or proof of concept, if safe to provide
- Any suggested mitigation

Please allow reasonable time for the issue to be investigated and addressed.

## Security Philosophy

SHIPSTACK treats security as an engineering requirement rather than a final
checklist item.

Security guidance should be supported by:

- Reproducible examples
- Tests where practical
- Threat models
- Documented assumptions
- Clear mitigation strategies
